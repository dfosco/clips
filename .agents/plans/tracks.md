# Add Tracks to Clips

Tracks are repository-scoped workstreams above goals. A goal belongs to at most one track and can depend on other goals. Existing goals remain unassigned. Tracks have their own status and show goal progress.

Implement track event logs and CLI commands, goal assignment and dependency validation, CLI and board views, native GitHub sub-issue mirroring for track-to-goal relationships, and workflow documentation. Verify legacy replay, dependency cycles, board grouping, and GitHub reconciliation with tests and a local CLI smoke check.
